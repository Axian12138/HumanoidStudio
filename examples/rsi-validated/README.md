# RSI 经测试验证的知识

本目录只收录从 `../rsi-learned/` 晋升的冻结版本，独立于 `../humanoid-real2sim/`。执行规则见 [RSI skill](../../codex_skills/evolve-humanoid-hoi-knowledge/SKILL.md)。当前没有已验证知识。

晋升需要冻结评估协议下的配对比较、实际改善及回归检查。记录 train 源版本、内容哈希、代码和依赖版本、评估协议及验证状态；不能根据 test 失败重写方法。测试详细材料放隔离 outputs，不作为学习检索内容。这里的通过表示知识筛选有效，不等于无偏最终泛化性能。

知识正文、代码或依赖改变后必须重新建立版本与验证证据。已证实基本错误的版本从当前目录、索引和检索缓存中删除；保留 outputs 中的审计记录，不把错误规则继续提供给 agent。

源机器人可以不同，但必须记录模型与手型、可迁移原则和G1适配方式；只有G1上的test通过才可进入已验证库。跨机器人测试不加载源模型，使用预计算的隔离交互参考与G1自身约束，规则见skill的跨机器人引用。
