# 当前实现边界

## 当前实现边界

第 3 阶段沿用现有运动学求解器。物理播放和抓取检验属于第 4/5 阶段，不作为第 3 阶段的优化器。

第 3.5 阶段已有直接设置 qpos 的独立运动学播放器。第 4 阶段的 RSS 编辑器已有五点接管、停止物理、播放、回滚、手部开关与候选导出。第 2 阶段可通过 RSS live page 和 `--scene-file` 接入；几何仍需 Blender/人工测量或其他可靠来源。第 5 阶段尚无通用的“拖动物体后连同柔性求解器状态一起分支回滚”的编辑器；目前修改场景/资产后需重建并重新跑第 4/5 阶段。没有 CUDA 时不能声称完成真实 BFM TensorRT rollout，也不能把假 tracker 的 smoke test 当作动力学验收。具体文件、命令和输出见 [本地接口](local-interfaces.md)。
